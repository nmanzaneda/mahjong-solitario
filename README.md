# Mahjong Solitario

Mahjong Solitario simple, sin publicidad y sin instalar nada. Hecho para jugar desde el celular.

- Tres niveles: Fácil (72 fichas), Mediano (104) y Clásico (tortuga de 144).
- Todas las partidas tienen solución.
- Pista, Deshacer y Mezclar.
- Guarda la partida automáticamente en el navegador.
- Funciona sin internet: es un solo archivo `index.html`.

## Cómo jugar en el celular
Abrí `index.html` (o la página de GitHub Pages) en Chrome y usá **⋮ → Agregar a la pantalla principal** para tenerlo como una app.
